# Cool Cat Ideas Code

Dark VS Code theme matching the syntax coloring used in Cool Cat Ideas articles.

![Cool Cat Ideas Code theme preview](./cool-cat-ideas-code-theme-preview.png)

## Local Installation

1. Unzip this package.

2. Copy the extension folder into your VS Code extensions directory using the following folder name:

   `coolcatideas.cool-cat-ideas-code-1.0.1`

   Full path:

   - Windows:
     `%USERPROFILE%\.vscode\extensions\coolcatideas.cool-cat-ideas-code-1.0.1`

   - macOS/Linux:
     `~/.vscode/extensions/coolcatideas.cool-cat-ideas-code-1.0.1`

   The folder name follows the VS Code extension ID format:

   `<publisher>.<name>-<version>`

3. Restart VS Code or run:

   `Developer: Reload Window`

4. Open:

   `Preferences: Color Theme`

5. Select:

   `Cool Cat Ideas Code`

## Verify Installation

You can verify that VS Code detected the extension by running:

```bash
code --list-extensions --show-versions
